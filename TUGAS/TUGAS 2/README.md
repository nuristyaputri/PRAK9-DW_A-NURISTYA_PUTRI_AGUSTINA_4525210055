# Selaras Coffee ☕

Website Selaras Coffee merupakan website profil UMKM kopi lokal yang menyediakan informasi mengenai produk kopi, profil usaha, promo, serta layanan kemitraan bisnis. Website ini dibuat untuk memperkenalkan produk kopi Nusantara kepada pelanggan dan memberikan informasi bagi calon mitra usaha.

## 📌 Fitur Website

- **Beranda** – Menampilkan informasi utama dan pengenalan Selaras Coffee.
- **Tentang Kami** – Menampilkan profil usaha, keunggulan, dan informasi mengenai kualitas produk.
- **Produk Unggulan** – Menampilkan daftar produk kopi beserta deskripsi dan harga.
- **Promo** – Menampilkan informasi promo pelanggan baru dan kemitraan melalui modal.
- **Form Kontak** – Formulir untuk pelanggan dan calon mitra yang ingin menghubungi Selaras Coffee.
- **Notifikasi** – Menampilkan pemberitahuan ketika formulir berhasil dikirim.
- **Navbar Responsif** – Navigasi website yang dapat menyesuaikan ukuran layar.
- **Footer** – Menampilkan informasi kontak, alamat, dan jam operasional.

## 🛠️ Teknologi yang Digunakan

- HTML5 – Membuat struktur halaman website.
- CSS3 – Mengatur tampilan dan desain website.
- Bootstrap 5.3.3 – Membantu membuat layout dan komponen responsif.
- Bootstrap Icons – Menampilkan ikon pada website.
- JavaScript – Mengatur interaksi form dan notifikasi.
- Google Fonts – Menggunakan font Playfair Display dan Poppins.

## 🎨 Desain Website

Website Selaras Coffee menggunakan konsep desain minimalis, hangat, dan elegan dengan perpaduan warna:

- Espresso: `#362214`
- Warm Cream: `#faf6f0`
- Caramel: `#b97a47`
- Soft Border: `#eadccf`

Desain dibuat agar memberikan kesan hangat dan sesuai dengan identitas brand kopi lokal.

## 🚀 Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder project Selaras Coffee.
3. Pastikan file `index.html` dan `style.css` berada dalam folder yang sama.
4. Buka file `index.html` menggunakan browser.
5. Website siap digunakan.

## 📱 Tampilan Responsif

Website dirancang menggunakan Bootstrap 5 sehingga dapat menyesuaikan tampilan pada berbagai ukuran layar, baik desktop, tablet, maupun smartphone.
